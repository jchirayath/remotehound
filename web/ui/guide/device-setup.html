Connect a computer to RemoteHound

These steps connect a Mac or a Windows PCthis computer so that the people who look after it can reach it from a browser. It takes about five minutes, and you only do it once. The one thing that changes from computer to computer is the six-character code. Read this page, then follow On a Mac or On a Windows PC.

You need

  • The code from the person who looks after the computer. It works once, for one computer, and expires after about 15 minutes, so start soon after you get it.shown on the right. It works once, for one computer.
  • The computer's administrator password (the one you type to install software).
  • An internet connection.
  • A Mac with macOS 10.12 Sierra or later.
  • A Windows PC with Windows 10 (version 1809 or later) or Windows 11.

Write your code hereYour code

For: this computer
Use it before it expires.

Lower-case letters and digits. A code never contains 0, o, 1, l or i, so there is nothing to mix up.

What you are agreeing to. After this, the people who have access in RemoteHound can open this computer's screen (or a terminal) from their browser without asking you each time. Every connection is recorded. The computer opens the connection itself, so no router or firewall changes are needed, and nothing new is opened to your home or office network. You can remove it at any time (last page).

The command you will type

Type it exactly as shown, and put your code where it says CODE. Everything else stays the same.

Type it exactly as shown. The highlighted part is this computer's code.

ComputerWhere to type it
MacTerminal
curl -fsSL https://your-server/e/CODE | sudo sh
WindowsPowerShell, opened with Run as administrator
irm https://your-server/e/CODE | iex

Example: if your code is k7q2mx, the Mac command is curl -fsSL https://your-server/e/k7q2mx | sudo sh. The | character is the vertical bar, usually Shift + the backslash key. Typing the command only downloads instructions from your RemoteHound server; nothing changes on the computer until you enter your password (Mac) or approve the administrator prompt (Windows).

On a Mac

Shown on macOS Sequoia. On macOS 12 Monterey and older, System Settings is called System Preferences, and Sharing is a top-level icon.

  1. Turn on Screen Sharing

    Open the Apple menu > System Settings > General > Sharing, and switch on Screen Sharing. This is the one setting a script is not allowed to change for you. (The script turns on Remote Login itself.)

    Select the ⓘ next to Screen Sharing. Under Allow access for, keep All users, or add the account the person who connects will sign in with. They sign in with that Mac account's user name and password.

  2. Keep the Mac awake

    A Mac that is asleep can't be reached. In System Settings:

    MacBook (laptop)Battery > Options… > switch on Prevent automatic sleeping on power adapter when the display is off and set Wake for network access to Only on Power Adapter or Always. Leave it plugged in, with the lid open.
    iMac, Mac mini, Mac StudioEnergy > switch on Prevent automatic sleeping when the display is off and Wake for network access.

  3. Open Terminal

    Press ⌘ Command + Space, type Terminal and press Return. (It is also in Applications > Utilities.)

  4. Type the command with your code, then press Return

    curl -fsSL https://your-server/e/CODE | sudo sh

    When it asks for Password:, type your Mac's login password and press Return. Nothing appears while you type, not even dots; that is normal.

  5. Wait for "Connected"

    The script works through six short steps and ends with Connected as and the computer's name, normally within a minute. If a Sharing window pops up at the script's step [4/6], check that Screen Sharing is on (step 1) and close it.

  6. Tell the person who sent the code that you are done

    You can close Terminal. The connection keeps running in the background and comes back by itself after a restart or a network change, even when nobody is logged in.

On a Windows PC

Shown on Windows 11; Windows 10 looks much the same. Remote Desktop needs Windows Pro, Enterprise or Education: to check, open Settings > System > About and look at Edition. On Windows Home the steps still work, but only a terminal connection is possible, not the desktop.

  1. Open PowerShell as administrator

    Click Start, type PowerShell, then choose Run as administrator on the right. When Windows asks "Do you want to allow this app to make changes to your device?", choose Yes. (If it asks for a password, use an administrator account's.)

    The window's title must start with Administrator:. If it doesn't, close it and open it again with Run as administrator. Use PowerShell, not Command Prompt: the command does not work in Command Prompt.

  2. Type the command with your code, then press Enter

    irm https://your-server/e/CODE | iex

  3. Wait for "Connected"

    The script turns on Remote Desktop for you (reachable only through RemoteHound; nothing is opened to your network) and ends with Connected as and the PC's name, normally within a minute.

  4. Check two settings

    The script turns on Remote Desktop itself. Two more settings decide whether anyone can actually get in:

    Keep the PC awakeSettings > System > Power & battery (Windows 10: Power & sleep) > Screen, sleep & hibernate timeouts: set When plugged in, put my device to sleep after to Never. Turning the screen off is fine. A sleeping PC can't be reached.
    Sign in with a passwordRemote Desktop needs the account's password, not a PIN, fingerprint or face. If you only ever use a PIN: Settings > Accounts > Sign-in options, switch off For improved security, only allow Windows Hello sign-in for Microsoft accounts on this device, then sign out and back in once with the password. For a Microsoft account, the password is the one for your Microsoft account online.
    Remote Desktop is onSettings > System > Remote Desktop shows On. The script switched it on; it is listed here so you know where to look, or to switch it off later.

  5. Tell the person who sent the code that you are done

    You can close PowerShell. The connection runs in the background, starts with Windows and reconnects by itself. Whoever connects signs in with a Windows account on this PC, so they need its user name and password (or their own account on it).

If something goes wrong

You seeWhat to do
"This code is not valid or has expired."The code was mistyped, already used or too old. Check it letter by letter; if it is right, ask for a new one.
"RemoteHound is busy … try again in a minute."Too many wrong codes were tried from your network. Your code is still good: wait a minute and run the same command again.
"This code is for a … machine, but this one reports …"The code was made for a different kind of computer (for example a Windows code on a Mac). Ask for a code for this computer; the old one was not used up.
Mac: "macOS needs Full Disk Access for your terminal app to change Remote Login"Either switch on Remote Login yourself in System Settings > General > Sharing, or allow Terminal in System Settings > Privacy & Security > Full Disk Access. Then run the command again.
Mac: "Sorry, try again."The password was wrong. Type your Mac login password again; nothing shows while you type.
Mac: "Could not read the key fingerprint (OpenSSH 6.8 or newer is needed)", or curl reports a certificate problemThis Mac's macOS is too old. It needs updating (at the Mac itself) before it can be connected.
Windows: "Not running as Administrator"PowerShell was not opened with Run as administrator. Close it, open it again as administrator (step 1 of the Windows page) and run the command again.
Windows: "irm is not recognized", or red text about "&"The command was typed in Command Prompt. Open PowerShell instead.
Windows: "This is Windows Home, which has no Remote Desktop server"Fine to continue; only a terminal connection will be possible. Upgrading to Windows Pro adds the desktop.
"The server has not seen the tunnel yet"Usually a network that blocks outgoing connections on port 2222 (some offices, schools and hotels). It keeps trying in the background. Send the person who gave you the code a photo of the last lines on screen.
Security software warns about the scriptSome antivirus and company security tools block or flag it. Don't override them on a work computer; tell the person who sent the code, who can give you a version that runs no script.

Running it again

Running the command again with a new code is safe: it replaces the computer's old registration. Tell the person who sent the code, so they can delete the old entry.

Removing RemoteHound

This stops the connection and deletes everything the script added. Screen Sharing, Remote Login and Remote Desktop are left as they are; turn them off in settings if you no longer want them.

Mac (Terminal)
sudo sh '/Library/Application Support/RemoteHound/uninstall.sh'
Windows (PowerShell as administrator)
powershell -ExecutionPolicy Bypass -File "C:\ProgramData\RemoteHound\uninstall.ps1"

The person who looks after the computer can also switch off its access in RemoteHound at any time; the connection then stops for good.
